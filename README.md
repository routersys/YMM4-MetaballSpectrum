# メタボール for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-MetaballSpectrum.svg)](https://github.com/routersys/YMM4-MetaballSpectrum/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、音声に合わせて液体のようにつながる塊を描く波形プラグインです。
YMM4から受け取った値を縦に伸びる塊として横に並べ、隣り合う塊の影響を足し合わせて、メタボールの形にします。
YMM4が計算した値だけを使い、音声データそのものは読み込みません。
同じ値と設定なら、常に同じ形に描きます。
幅、高さ、塊の半径、融合のしきい値、縁の太さ、縁の明るさの6項目はアニメーションに対応しています。

## 概要

本プラグインはYMM4の図形アイテムの波形として動作し、「波形の種類」では「メタボール」として表示されます。左右に並んだ丸みのある塊が、音の大きさに合わせて縦に伸び縮みし、隣り合う塊は、距離が近いと水滴がくっつくようになめらかにつながります。塊の位置は動かず、動くのは高さだけです。

YMM4から受け取った値1つにつき、塊が1つできます。塊は横に等間隔に並び、塊の中心は、「高さ」の範囲の下の辺（以下、下端）から、値の絶対値に比例した高さまで伸びる縦の線分です。この線分のまわりが丸くふくらんだ形が、塊として描かれます。

メタボールは、丸い塊が近づくと、境目がなめらかにつながって1つの形になる表現です。本プラグインでは、塊が周りへ及ぼす影響を、塊から遠いほど小さくなる値で表します。画面上の各点で、すべての塊の影響を足し合わせたものを密度と呼びます。密度が「融合のしきい値」以上の部分を内側として塗ります。内側と外側の境目を表面と呼び、表面に沿って縁を描きます。

処理はDirect2Dのカスタムピクセルシェーダーが行い、CPUは受け取った値と設定をシェーダーの定数として渡します。CPUへの画素の読み戻しはありません。設定は図形アイテムの波形の項目としてプロジェクトに保存し、プラグイン自体の設定ファイルは持ちません。

このプラグインはAviUtl向けのEXO出力には対応していません。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-MetaballSpectrum/releases/latest)ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4を起動し、図形アイテムの「種類」を「波形」にします。
4. 「波形 / 描画」にある「波形の種類」で「メタボール」を選びます。既定の設定では、幅600pxの範囲に塊が等間隔に並び、最大300pxの高さまで伸びます。「表示形式」が既定の「スペクトラム」のとき、YMM4の既定では値は32個で、隣り合う塊がつながり、上辺が波打つ1つの形に見えます。見た目は「塊の半径」と「融合のしきい値」で調整してください。「縁の明るさ」を調整するときは、先に「色」を白以外にしてください。

## 主な機能

### 1. 塊の並びと高さ

「幅」は、塊が並ぶ範囲の横幅です。受け取った値の数で幅を等分し、等分した区画の真ん中に、塊を1つずつ置きます。並びは図形の中央を中心にして、左右へ半分ずつ広がります。幅を広げると塊の間隔が空いてつながりにくくなり、狭めるとつながりやすくなります。値の数は、YMM4の「波形 / 表示データ」の設定で決まり、このプラグインの項目にはありません。「表示形式」が「スペクトラム」のときは、「解像度」の値です。

「高さ」は、値が最大のときに塊が伸びる高さです。受け取った値は-1から1の範囲に収めてから使います。「両側に描く」がオフの既定では、値の絶対値が1のとき、塊の中心の線分は下端から高さいっぱいまで伸びます。絶対値が0.5のときは、高さの半分まで伸びます。

値が0でも塊は消えず、下端に1点の塊が残ります。既定の設定では、隣り合う塊がつながるため、無音のときは下端に沿った帯が描かれます。

### 2. 塊の大きさと融合

「塊の半径」は、見える塊の半径ではなく、塊の影響が届く距離です。塊の中心の線分からの距離を$`d`$、半径を$`R`$とすると、1つの塊の影響は$`(1 - (d/R)^2)^3`$で、$`d`$が$`R`$以上のところでは0です。半径を大きくすると、塊が太くなり、離れた塊ともつながります。

「融合のしきい値」は、密度がどこから内側になるかを決める割合です。塊1つだけの密度は、中心の線分の上で最大になります。この最大値を100%とします。塊が1つだけのとき、表面は塊の中心の線分から、$`R \times \sqrt{1 - \sqrt[3]{\text{しきい値}}}`$の距離にあります。ここで、しきい値は45%なら0.45として扱います。次の表は、半径が36pxの塊1つについて、しきい値ごとに、中心の線分から表面までの距離を示します。

| しきい値 | 線分から表面まで |
|---|---|
| 5% | 約28.6px |
| 25% | 約21.9px |
| 45%（既定） | 約17.4px |
| 70% | 約12.1px |
| 95% | 約4.7px |

しきい値を下げると塊が太り、上げると細ります。高さが同じで隣り合う2つの塊は、しきい値が45%のとき、中心の間隔が半径の約1.25倍以内ならつながります。しきい値を上げるとつながる間隔は狭くなり、95%では半径の約0.94倍以内になります。

### 3. 縁

「縁の太さ」は、表面に沿って描く縁の幅です。縁は表面をはさんで内側と外側に広がります。外側にも縁が描かれるため、縁を太くすると全体が外へ広がります。縁の端はなめらかに透明へ変わり、0pxにすると縁は描かれません。

縁の太さは、表面からの距離を、その点での密度の変化の大きさから見積もって決めます。この見積もりは表面から離れるほどずれるため、4px程度まではほぼ指定した値のとおりに描かれ、それより太くすると指定した値より細く描かれます。たとえば、塊が1つで、半径が36px、しきい値が45%のとき、30pxの縁はおよそ20pxの幅になります。

「縁の明るさ」は、縁の色を白へ寄せる度合いです。0%では縁は塊と同じ色になり、100%では縁の中心が白になります。「色」が白のときは、縁の明るさを変えても見た目は変わりません。

### 4. 両側に描く

「両側に描く」をオンにすると、図形の中央の水平線から、値が正の塊は上へ、負の塊は下へ伸びます。値の絶対値が1のとき、塊の中心の線分は水平線から「高さ」の半分まで伸びます。値が0の塊は水平線上に残ります。

YMM4の「表示形式」が「スペクトラム」のときは値が0以上なので、オンにしても、塊は上へ伸びるだけです。伸びる長さは最大でも「高さ」の半分で、オフのときより短くなります。「表示形式」が「波形」のときは値が負にもなるため、波の上下を形に生かしたいときは、オンにしてください。オフでは、値の符号を使わず、絶対値の分だけ下端から上へ伸ばします。

### 5. 色と出力の範囲

「色」は、塊の色です。不透明度を下げると、塊と縁は半透明になります。

図形の出力範囲は、「幅」と「高さ」で決めた範囲を、上下左右へ余白の分だけ広げた大きさです。余白の長さは、「塊の半径」に「縁の太さ」の半分と2pxを足した長さです。塊は中心の線分より外へふくらむため、塗られる範囲が「幅」と「高さ」の範囲からはみ出すことがあります。はみ出しても、塊と縁はこの出力範囲の内側に収まります。

| パラメータ名 | 型 | デフォルト | スライダー表示範囲 | アニメーション | 説明 |

| 高さ | 数値 | 300px | 0〜1080px | 対応 | 値が最大のときに塊が伸びる高さです。「両側に描く」がオンのときは、上下それぞれ高さの半分までです。直接入力では0.01〜100000pxまで指定できます。 |
| 塊の半径 | 数値 | 36px | 1〜120px | 対応 | 塊の影響が届く距離です。大きくすると、塊が太くなり、離れた塊ともつながります。直接入力では0.01〜100000pxまで指定できます。 |
| 融合のしきい値 | 数値 | 45% | 5〜95% | 対応 | 密度がこの値以上の部分を内側にします。塊1つだけのときの最大の密度を100%とします。下げると塊が太り、つながりやすくなります。上げると細り、つながりにくくなります。直接入力では0.1〜99.9%まで指定できます。 |
| 縁の太さ | 数値 | 4px | 0〜30px | 対応 | 表面に沿って描く縁の幅です。太くすると全体が外へ広がり、0pxでは縁を描きません。直接入力では0〜100000pxまで指定できます。 |
| 縁の明るさ | 数値 | 60% | 0〜100% | 対応 | 縁の色を白へ寄せる度合いです。「色」が白のときは変わりません。 |
| 両側に描く | ON/OFF | OFF | — | 非対応 | 図形の中央の水平線から、値が正の塊は上へ、負の塊は下へ伸ばします。OFFでは、下端から上へ伸ばします。 |

## 制限事項

- AviUtl向けのEXO出力には対応していません。
- Direct2Dがカスタムエフェクトの作成を受け付けない場合は、何も描きません。
- 受け取った値が1つもないときは、何も描きません。
- 受け取った値が256個を超えるときは、256個のまとまりに分け、まとまりごとに絶対値がいちばん大きい値を使います。
- 塊の内側は一色で塗ります。グラデーションと画像は使えません。
- 塊は並びの位置に固定され、横へは動きません。動くのは、値に応じて伸びる高さだけです。
- 縁の太さは表面の近くでしか指定した値に合わないため、縁を太くするほど、指定した値より細く描かれます。

## 注意事項

- 処理負荷: 画素ごとに、「塊の半径」が届く横の範囲にある塊の数だけ計算します。「塊の半径」が大きく、「幅」が狭く、受け取る値の数が多いほど、処理は重くなります。重いときは、「塊の半径」を小さくしてください。
- 再現性: 結果は受け取った値と設定だけから決まり、時刻と乱数は使いません。同じ値と設定なら、何度描いても同じ形になります。
- 更新通知: 新しい正式版の確認は、「波形の種類」で「メタボール」を選んだときと、メタボールの波形があるプロジェクトを開いたときに、YMM4の実行中に一度だけ行います。新しい正式版があるときは、メッセージで知らせます。更新情報を取得できない場合は通知せず、そのまま動作します。プレリリースは通知の対象に含めません。
- 不具合の自動送信: 想定していない例外が起きたときは、その内容を開発者へ自動で送信します。内容は「不具合の報告」に書いています。
- 本プラグインを使用する前に、YMM4のプロジェクトファイルのバックアップを作成することを推奨します。

## 不具合の報告

本プラグインは、想定していない例外が起きたときに、その内容を開発者へ自動で送信します。同意は求めず、常に送信します。

送信する情報は次のとおりです。

| 種類 | 内容 |
|---|---|
| 例外 | 型の完全名、メッセージ、スタックトレース |
| 発生位置 | モジュール名、関数名、ファイル名、行番号 |
| プラグイン | アセンブリ名、バージョン |
| 実行環境 | OSの名前とバージョン、.NETのバージョン、CPUのアーキテクチャ、論理プロセッサ数 |
| 識別子 | YMM4の起動ごとに決まるセッション識別子、報告ごとの識別子 |

メッセージとファイル名は、送信の前に置き換えを通します。置き換えるのは、Windowsのユーザー名、ユーザーフォルダー、AppDataのパス、マシン名、ドメイン名、メールアドレス、IPv4アドレスです。送信元のIPアドレスは受信側へ渡す手前で取り除いています。

音声の内容、映像の中身、プロジェクトの内容は送信しません。継続して個人を追跡する識別子も持ちません。セッション識別子はYMM4を起動し直すと別の値になります。

送信するのは想定していない例外だけです。YMM4が本プラグインの波形の設定を作るとき、描画を準備するとき、フレームごとに更新するとき、破棄するときと、Direct2Dがシェーダーの定数を書き込むときに起きた例外を報告し、その後はYMM4へそのまま渡します。更新の確認では、更新情報の取得と比較で起きた例外は報告しません。通知の文を組み立てて表示するときに起きた例外は報告し、YMM4へは渡しません。画面の操作やバックグラウンドの処理で未処理になった例外も報告しますが、本プラグインのコードが関わる例外に限ります。本プラグインの外で起きた例外は送信しません。

次の失敗は送信しません。

| 種類 | 例 |
|---|---|
| 何も描かないだけで済ませるもの | Direct2Dのカスタムエフェクトを作成できないときに、何も描かなかったとき |
| 更新の確認の通信の失敗 | manjubox.netとGitHubのどちらへも接続できない |

送信できなかった報告はYMM4のユーザーフォルダーへ退避します。次にYMM4を起動したあと、本プラグインの波形の設定を作るか、同じくYMM4-Telemetryで報告する別のプラグインが動き始めると、退避した報告を1回の起動で10件まで送り直します。送信も再送も非同期に行うため、通信を待って起動と描画が遅くなることはありません。

実装は [YMM4-Telemetry](https://github.com/routersys/YMM4-Telemetry) をサブモジュールとして取り込んでいます。
